Proyecto Final de Paradigmas y Programación para Ciencia de Datos

This Project applied four machine learning algorithms (Logistic Regression, Random Forest, Naive Bayes, and XGBoost) to an H&M dataset to predict up to 12 items each customer would purchase in the next seven days. The best algorithm and parameters were then determined using mesh analysis.
